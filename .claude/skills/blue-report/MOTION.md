# 효과 라이브러리 — 요청이 있을 때 여기서 고른다

발표 덱(기준 덱 · 라이브 계통)의 애니메이션 · 효과 메뉴판이다. 효과는 이 파일 순서대로 고른다.
기준은 2026-10 사내 발표 덱 최종본이다. 거기서 실제로 쓴 연출을 모양대로 묶었고, 내용(조직 · 수치)은
옮기지 않았다. 견본은 전부 `assets/live-catalog.html` 에 가상 데이터로 들어 있다.

## 0. 언제 쓰나

- **기본은 부품에 든 움직임만.** 막대 성장 · 도넛 그리기 · 흐름선 · 숫자 세기처럼 부품이 저절로
  하는 움직임 외에는 효과를 덧붙이지 않는다.
- **사용자가 「애니메이션 · 효과 · 움직임을 넣어 달라」고 하면** 이 파일에서 고른다. 장마다 내용을
  보고 아래 「2. 연출 패턴」 중 맞는 것을 먼저 찾고, 없으면 「3. 단일 효과」를 조합한다.
- 효과를 새로 짤 때만 장 안 `<style data-own>` 에 `@keyframes` 를 적는다(「5」).

## 1. 원칙 — 효과는 읽는 순서를 안내한다

| 한다 | 하지 않는다 |
|---|---|
| 읽는 순서대로 하나씩 — 순번 `--i` 로 0.08초씩 | 한 장의 모든 요소가 동시에 뜨기 |
| 값은 그려지며 — 막대가 자라고 선이 그어지고 숫자가 오른다 | 값과 관계없는 회전 · 흔들림 |
| 강조는 마지막 — 강조 막대 · 도장 · 결론 띠는 `--d` 로 늦게 | 강조가 먼저 나와 나머지를 가리기 |
| 반복은 「지금 · 흐름 · 처리 중」에만 — 지금 역 맥박, 흐르는 점선 | 장식으로 계속 깜빡이는 요소 |
| 시선을 끄는 반복은 한 화면에 한 곳 | 반복 움직임 여러 개가 서로 경쟁 |
| 감속 모드에서는 처음부터 최종 모습 | 움직임에만 정보를 싣기 |

## 2. 연출 패턴 — 조합 레시피

카탈로그 장 id 로 열어(`live-catalog.html#장id`) 보고, 장째 복사하거나 레시피만 옮긴다.

| 패턴 | 이럴 때 | 레시피 | 카탈로그 |
|---|---|---|---|
| **M01 데이터 그리기** | 수치 비교 · 순위 · 처리 시간 | 막대 `bl-a--gx` 에 순번 `--i` · 강조 막대는 `--d: .6s` · 큰 숫자 `data-count` · 결론 도장 `bl-stamp` `--d` 마지막 | `mx-data` |
| **M02 경로 그리기** | 연혁 · 로드맵 · 지금 위치 | 선 `<path pathLength="1" class="bl-a bl-a--draw">` → 역 `bl-a--pop` 순번 → **지금 역 하나만** `bl-a--pulse` | `mx-path` |
| **M03 단계 전개 + 흐리게** | 발표자가 한 줄씩 끊어 말할 때 | 장에 `data-dim` · 줄마다 `data-f="1"…` · 노트에 `[클릭]` 같은 수 | `mx-steps` |
| **M04 전과 후** | 지금 방식 → 바뀐 방식 | 지금 쪽 `bl-a--strike` 순번 → 바뀐 쪽 `bl-a--tint` 순번 → 결론 띠 `bl-a--up` `--d` 마지막 | `mx-swap` |
| 흐름 · 모임 | 여러 창구 → 한 곳 → 여러 쓰임 | 곡선 `bl-fl` + 선 위 점 `bl-fl-dot`(`<animateMotion>`) · 계획은 점선 `bl-fl--dash` | `flow` |
| 노선 · 자동 순환 | 단계마다 상세가 있는 경로 | `bl-route` — 역이 저절로 돌며 오른쪽 카드가 바뀜 | `route` |
| 장면 넘김 | 화면 시연 · 절차 시연 | `bl-scenebox` — 단계마다 장면 교체, 목록 단추로 자동 재생 | `coach` |
| 화면 데모 | 실제 화면 위 동작 | `bl-mock` + 커서 `bl-cursor` + 캡션 바 `bl-capbar` · 다시 재생 `bl-replay` | `explorer` |
| 숫자 강조 | 핵심 수치 하나 | `data-count`(0 → 값) · `data-count="roll"`(자리마다 굴러 멈춤) | `kpi` · `motion` |

## 3. 단일 효과 — 22종

요소에 `bl-a` 와 `bl-a--계열` 을 함께 단다. 장이 화면에 들어오면 한 번 재생한다(단계로 열리면 그때).
견본은 카탈로그 `motion` 장.

| 클래스 | 효과 | 뜻 · 쓰는 자리 | 길이 |
|---|---|---|---|
| `bl-a--up` | 아래에서 떠오름 | 카드 · 행 · 문장의 기본 등장 | .55s |
| `bl-a--left` | 왼쪽에서 들어옴 | 순서가 왼쪽→오른쪽인 흐름 | .55s |
| `bl-a--fade` | 페이드 | 보조 요소 · 배경 · 주석 | .55s |
| `bl-a--pop` | 튀어나옴 | 노드 · 핵심 숫자 · 아이콘 | .55s |
| `bl-a--drop` | 위에서 떨어짐 | 새로 들어오는 항목 · 추가분 | .7s |
| `bl-stamp` | 도장 | 결론 · 판정 · 승인 — 장마다 하나 | .5s |
| `bl-a--gx` · `bl-a--gy` | 가로 · 세로로 자람 | 막대 · 게이지 · 면적 | 1s · .9s |

| `bl-a--type` | 타자 | 입력 · 프롬프트 · 검색어 (`--n` 글자 수) | 글자당 .07s |
| `bl-a--strike` | 취소선 | 없애는 것 · 바뀌기 전 | .6s |
| `bl-a--tint` | 흑백 → 컬러 | 새로 생기는 것 · 바뀐 뒤 | .8s |
| `bl-a--shake` | 흔들림 | 알림 · 경고 — 아주 드물게 | .9s |
| `data-count` · `data-count="roll"` | 숫자 세기 · 굴림 | 핵심 수치 | 1.1s |
| `bl-a--pulse` | 맥박(반복) | **지금 위치** · 오늘 · 진행 중 | 1.8s |
| `bl-a--ripple` | 파문(반복) | 신호 · 발생 지점 | 1.8s |
| `bl-a--glow` | 발광(반복) | 선택된 칸 · 지금 단계 바탕 | 1.8s |
| `bl-a--blink` | 깜빡임(반복) | 대기 · 수신 중 | 1.4s |
| `bl-a--flow` · `bl-fl--dash` | 흐르는 점선(반복) | 흐름 방향 · 진행 중 연결 | 1.6s |
| `bl-a--run` | 경로 이동(반복) | 운반 · 이동하는 것 (`--t` 한 바퀴) | 9s |
| `bl-a--spin` | 회전(반복) | 처리 중 · 동기화 (`--t`) | 4s |

곡선은 계통 것 그대로(`--bl-ease` · `--bl-ease-out` · `--bl-ease-pop`).

## 4. 단계 전개

- 요소에 `data-f="1"` 부터. 같은 번호는 함께 열린다. 발표 모드와 펼침을 끈 상태(X)에서만 접힌다.
- 장의 노트에 `[클릭]` 을 단계 수 이상 적는다 — 대본 창 배지가 단계와 맞는다(검사기 24번).
- 장에 `data-dim` 을 달면 **지난 단계가 28% 로 흐려진다** — 지금 말하는 줄만 또렷하다(M03).
- 단계 안의 `bl-a` 효과는 그 단계가 열리는 순간 재생된다.

## 5. 효과를 새로 짤 때

라이브러리에 없는 연출이 꼭 필요할 때만. 장 안 `<style data-own>` 에 적는다.

```html
<style data-own>
  @media (prefers-reduced-motion: no-preference) {
    html.bl-anim #장id:not(.in) .x-node { opacity: 0 }             /* 장에 들어오기 전 */
    #장id.in .x-node { animation: xRise .6s var(--bl-ease) both;     /* 들어오면 재생 */
                       animation-delay: calc(var(--i, 0) * .08s) }
  }
  @keyframes xRise { from { opacity: 0; transform: translateY(.8rem) } to { opacity: 1; transform: none } }
</style>
```

- 감속 모드 분기 안에서만 숨기고 움직인다. 밖에서는 최종 모습.
- 곡선은 `var(--bl-ease*)`(반복은 `linear` 허용), 길이 0.15~2.4초(반복 12초까지), 색은 토큰만.
- 검사기 28번이 이 규칙을, 30번이 장마다 효과 수(등장 3종 · 반복 2종 넘으면 주의)를 본다.

## 6. 확인

- `check_live.py <결과> --shots out/` — 실패 0. 30번 주의가 뜨면 그 장의 효과를 줄이거나 반복을 한 곳으로 모은다.
- 정지 화면은 최종 모습만 보인다. 효과를 넣은 장은 브라우저에서 넘겨 보며 순서와 속도를 확인한다 —
  발표 모드(Shift+F5)에서 단계까지 밟아 본다.
