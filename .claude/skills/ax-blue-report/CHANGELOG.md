## 1.0.0 — 2026-10-06

**첫 판.** 사내 경영진 보고 덱 최종본의 디자인 · 움직임 · 발표 기능을 스킬로 옮겼다.
내용은 한 줄도 옮기지 않았다 — 회사 · 기관 · 인물 · 수치 · 근거를 전부 가상 시나리오(「샘플테크」)로 바꾸고,
화면 캡처 · 포스터 · 영상 · 원문 문서도 「예시 · 가상」 표기 견본으로 갈았다.

| 무엇 | 내용 |
|---|---|
| 장 | 56종 — 본문 36 · 부록 간지 1 · Q&A 4 · 부록 도해 14 · 표지 |
| 엔진 | 클릭 단계 · 등장 애니메이션 · 펼침 · 가로/세로 스냅 · 메모 · 발표 모드 · 레이저 · 대본 창 · 숫자 점프 · 근거 창 · 원문 보기 겹창 · 영상 · 탭 |
| 빌드 | `build_deck.py` — 한 파일 HTML · `--present` · `--artifact` · 폰트 서브셋 · `data-t` 번호와 바닥줄 문서명 자동 |
| 출력 | `make_pdf.py`(상세 쪽 끼우기 · 두 화면 쪽 · 링크 · 책갈피 · 쪽 이름 · 고정 굵기 폰트) · `make_pdf_viewer.py` · `export_script.py` |

원본 덱에서 함께 고친 것

- 근거 창을 닫은 뒤 창 크기가 바뀌면 `clientWidth` 오류가 나던 것(뷰어 요소가 없을 때 계산하지 않는다).
- 쓰이지 않는 CSS 선택자 · 빈 스크립트 블록 정리(CSS 1.73MB → 약 0.95MB · 주석 제거).
- 발표 전용 판을 문자열 바꿔치기가 아니라 엔진 설정(`window.AXBR_MODE = 'present'`)으로 만든다.
