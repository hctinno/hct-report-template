# 로드맵

현재 상태와 다음 단계를 적는다. 완료 표시는 테스트로 확인된 것만 한다.

## 1단계 — 골격 (완료)

- [x] 루프백 전용 백엔드 추상화와 Ollama 어댑터
- [x] 하이브리드 검색(BM25 + 벡터, RRF 결합)
- [x] 한국어 어절·바이그램 토크나이저
- [x] 입력 가드와 비밀정보 마스킹
- [x] 근거 주입 방어
- [x] 인용 검증
- [x] 해시 체인 감사 로그
- [x] egress 실측 격리 점검
- [x] internal 네트워크 compose 구성
- [x] 골든셋 평가기
- [x] CLI 5개 명령
- [x] 표준 라이브러리 테스트 98건

## 2단계 — 실사용 검증

- [ ] 실제 사내 문서 300건 이상으로 색인 검증
- [ ] 실제 질의 30건 이상으로 골든셋 구성
- [ ] Gemma 계열 12B 와 27B 인용 준수율 비교 계측
- [ ] 사번·문서번호 등 사내 형식 마스킹 규칙 추가
- [ ] CPU 추론 지연 실측과 사용자 수용 한계 확인

## 3단계 — 운영 편의

- [ ] 증분 색인. 체크섬이 바뀐 문서만 재처리
- [ ] 최소 웹 UI. 내부 네트워크 안에서만 접근
- [ ] 다중 코퍼스 분리. 부서별 접근 범위 구분
- [ ] 감사 로그 회전과 장기 보관 정책

## 4단계 — 확장 검토

아래는 필요가 확인된 뒤에 한다. 지금 하면 격리 경계만 넓어진다.

- [ ] 청크 10만 초과 시 근사 최근접 색인
- [ ] 재순위 모델 도입과 비용 대비 효과 계측
- [ ] 표·이미지가 섞인 문서 처리
- [ ] 다중 사용자 동시 질의 큐

## 하지 않기로 한 것

| 항목 | 이유 |
| --- | --- |
| 외부 LLM API 폴백 | 폐쇄망 전제가 깨진다 |
| 별도 벡터 DB 서비스 | 격리 경계와 감사 대상이 늘어난다 |
| 자동 모델 다운로드 | 반입 절차를 우회한다 |
| 바이너리 문서 파서 | 공격 표면이 늘어난다. 변환은 반입 전 단계에서 |
| 형태소 분석 사전 반입 | 반입 검증 부담 대비 이득이 작다 |
