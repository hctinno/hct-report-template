# 아키텍처

## 전제

호스트 PC 는 사내망에 연결돼 있다. 격리 대상은 PC 가 아니라 **추론 런타임과
그 위의 응용**이다. 호스트를 끊으면 업무가 멈추므로, 경계를 컨테이너에 둔다.

```
┌─ 호스트 PC (사내망 연결) ─────────────────────────────┐
│                                                        │
│   운영자 ──docker compose run──┐                       │
│                                │                       │
│   ┌─ ai_internal (internal: true, 게이트웨이 없음) ─┐  │
│   │                            ▼                     │  │
│   │   ┌──────────┐      ┌──────────────┐            │  │
│   │   │   app    │─────▶│   runtime    │            │  │
│   │   │ CLI/RAG  │ HTTP │ Ollama/GGUF  │            │  │
│   │   └────┬─────┘      └──────────────┘            │  │
│   │        │                                         │  │
│   │        ├── corpus (ro)  ── 색인 대상 문서        │  │
│   │        ├── index  (rw)  ── vectors.jsonl, bm25   │  │
│   │        └── audit  (rw)  ── 해시 체인 감사 로그   │  │
│   └───────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

내부 네트워크에는 기본 게이트웨이가 붙지 않는다. 방화벽 규칙으로 막는 것이
아니라 경로 자체가 없다. 규칙은 사람이 지우지만 없는 경로는 지울 것이 없다.

## 계층

| 계층 | 모듈 | 책임 |
| --- | --- | --- |
| 설정 | `config.py` | 환경변수·.env 병합, 원격 URL 거부 |
| 백엔드 | `llm/` | 로컬 런타임 호출. 루프백만 허용 |
| 검색 | `rag/` | 적재·청킹·BM25·벡터·하이브리드 결합 |
| 하네스 | `harness/` | 가드·프롬프트·인용 검증·파이프라인 |
| 보안 | `security/` | egress 실측, 마스킹, 감사 체인 |
| 진입점 | `cli.py` | ingest / ask / doctor / eval / audit |

## 질의 흐름

```
질문
 └─ guard_input          비밀정보 마스킹, 길이 상한
     └─ HybridRetriever  BM25 순위 + 벡터 순위 → RRF
         └─ sanitize_context   문서에 심긴 지시문 무력화
             └─ build_messages 예산 안에서 근거 블록 구성
                 └─ backend.chat   로컬 추론
                     └─ verify_citations  인용 범위 검사
                         └─ AuditLog      해시 체인 기록
```

각 단계의 판정은 `Answer` 에 남는다. "왜 이렇게 답했나" 를 사후에 되짚기
위해서다.

## 의존성 정책

표준 라이브러리만 쓴다. 이유는 두 가지다.

- 폐쇄망에는 pip 인덱스가 없다. 휠 반입은 그 자체로 공급망 검증 대상이다.
- 벡터 DB 를 별도 서비스로 두면 격리 경계와 감사 대상이 함께 늘어난다.

성능 한계에 부딪히면 그때 도입한다. 현재 구조는 수만 청크 규모를 가정한다.
그 이상은 `docs/ROADMAP.md` 의 확장 항목을 참고한다.
