# BRAND — 로고 · 색 · 글꼴 · 크기 · 톤

값의 원본은 `assets/blue-report.css`(`--br-*`) · `assets/blue-live.css`(`--bl-*`) · `assets/blue-doc.css`(`--bd-*`)다.
이 문서는 **쓰는 법**을 정한다. 값을 여기서 고치지 않는다 — 값은 CSS 를 고치고, PPT 는 그 CSS 를 읽는다.

## 1. 로고

| 파일 (`brand/hct/`) | 쓰는 곳 |
|---|---|
| `hct-logo-color.png` | 밝은 지면 · A4 머리말 |
| `hct-logo-white.png` | 어두운 지면(표지 · 간지 · 머리띠) |
| `hct-logo-symbol-color.png` · `-white.png` | 배경 워터마크 전용(국문 병기 없는 심볼) |
| `hct-logo-source.png` | 원본 — 직접 쓰지 않는다 |

- 자리: 덱은 모든 장 머리띠 **우측 상단**, A4 · Word 는 모든 쪽 머리말 **왼쪽**(오른쪽은 문서번호). 빌드가 단다 — 본문에 직접 넣지 않는다.
- 면에 따라 고른다: 로고 원색(2016 CI 블루 `#0054a4`)은 표지 네이비 위에서 대비 2.24:1 이라 보이지 않는다 → 어두운 면은 흰색판.
- 금지: 늘이기 · 기울이기 · 색 바꾸기 · 그림자 · 테두리 · 사진 위에 바로 얹기 · 다시 그리기.
- 한계: 로고 영역 264×86px. 화면 발표에는 충분하고 인쇄 확대에는 부족하다(SVG 원본 확보 전).
- `brand.json`: 회사명 「주식회사 에이치시티」· 워드마크 「HCT」· 저작권 연도. 내부 배포라 연락처는 넣지 않는다.

## 2. 색 — 이름이 아니라 역할로

| 역할 | 토큰 | 값 | 쓰는 자리 |
|---|---|---|---|
| 주 강조 · 브랜드 | `--br-cobalt` | `#0054a4`(CI 블루) | 기본 강조 · 번호 머리 · 주인공 막대 |
| 깊은 값 | `--br-navy` | `#0b2a6b` | 키워드 볼드 · 큰 수치 · 표 머리선 |
| 표지 · 간지 | `--br-cover` | `#071b45` | 표지 · 장 간지 · 머리띠 · 꼬리띠 |
| 지면 · 카드 | `--br-page` · `--br-card` | `#f7f9fc` · `#ffffff` | 밝은 본문 지면 · 요점 카드 |
| 대조군 바탕 | `--br-tint` | `#eef2f8` | 비교 대상 카드 · 칩 · 결론 띠 바탕 |
| 글자 | `--br-text` · `-2` · `-3` | `#10151c` · `#54606e` · `#8b98a6` | 본문 · 보조 · 주석 |
| 당사 · 결과 (발표) | `--bl-pt-orange` | `#d07a1f` | 당사 막대 · 결과 화살 · 결론 강조어 |
| 비교 대상 (발표) | `--bl-pt-gray` | `#9aa4bb` | 업계 · 경쟁 · 과거 — 주인공을 돋보이게 물림 |
| 상태 | `--br-ok-*` · `--br-warn-*` · `--br-alert-*` | 글자 `#0f6b3f` · `#8a5a00` · `#a33418` | 상태를 말할 때만. 장식 금지 |
| 계열 구분 | `--br-cat-1~6` | `#0054a4` · `#c86a1a` · `#8341c4` · `#0d6b45` · `#0d88a8` · `#c02535` | 순서 없는 항목(부서 · 제품). 1번이 언제나 CI 블루 |

- 한 장의 강조색은 **하나가 주인공** — 대개 CI 블루, 당사 결과를 말할 때 주황.
- 비교는 「주인공 색 하나 + 회색」. 여러 색을 같은 무게로 늘어놓지 않는다.
- 상태는 색만으로 말하지 않는다 — 칩 글자(「달성」 「지연 위험」)를 함께.
- 밝은 지면에 `--br-soft-*` 를 쓰지 않는다(대비 부족 — 다크면 전용).

## 3. 글꼴

| 쓰임 | 글꼴 | 토큰 |
|---|---|---|
| 한글 · 본문 · 제목 · 수치 | Pretendard(서브셋 내장) | `--br-font-kr` · `--br-font-num` |
| 세는 숫자 · 머리 라벨 | IBM Plex Mono | `--bl-font-mono` |
| PowerPoint | Pretendard — 설치되지 않은 PC 는 다른 글꼴로 바뀐다(그림 속 글자는 영향 없음) | `pptx/tokens.js` |
| A4 공식 문서(기본 양식 `hct-official`) | 본문 명조 — HTML · PDF 는 내장 Noto Serif KR, Word 는 「바탕」. 장 제목 · 목차 장 줄은 굵은 고딕(HTML Pretendard, Word 「맑은 고딕」) | `forms/hct-official.json` |
| Word | 양식의 `font.*.word` — 표준 양식은 Pretendard(설치되지 않은 PC 는 다른 글꼴). 한글 · 숫자 사이 자동 띄움은 끈다 | `docx/from_doc.js` (색은 `pptx/tokens.js`) |

## 3-1. 회사 공식 문서 양식 (A4 기본 · `forms/hct-official.json`)

사내 규정 · 강령 원본(윤리강령)을 잰 양식이다. A4 문서의 기본이다.

| 자리 | 모양 | 토큰 |
|---|---|---|
| 머리말 | 왼쪽 문서명(명조 12pt 굵게 · 딥 블루) · 오른쪽 로고(8mm) · 아래 두 줄 선(딥 블루 0.6mm + CI 블루 0.25mm). 사선 없음 | `--br-deep` · `--br-cobalt` |
| 장 제목 | 위아래 1pt 딥 블루 선 상자, 왼쪽 10mm 번호 칸(Ⅰ Ⅱ …) 딥 블루 면 + 흰 숫자, 굵은 고딕 13pt · 딥 블루 | `--br-deep` |
| 표 · 문서 정보 · 결재란 | 이름 칸 아주 옅은 회청 + 딥 블루 굵은 글자, 위 굵은 선 딥 블루, 가는 괘선 옅은 회청 | `--br-tint` · `--br-form-rule` |
| 상자 · 칩 · 증감 | 상자는 가는 회청 테두리 + 옅은 면, 머리 글자만 색(안내 딥 블루 · 주의/경고 빨강), 칩은 면 없이 테두리, 증감은 나쁜 값만 빨강 | `--br-cobalt` · `--br-alert-text` |
| 본문 | 명조 11pt(표 · 문서 정보 표 같음) · 행간 1.75 · 양쪽 정렬 · 「1. 항목」 5mm, 「- 세부」 9.5mm(이어지는 줄 14mm), 호 번호 ①② | `--br-text` |
| 표지 | 가운데 정렬 — 오른쪽 위 로고 · 문서명(명조 26pt 굵게 · 딥 블루) · 부제 · 두 줄 선(딥 블루 + CI 블루, 폭 60%) · 아래 문서 정보 줄(`data-doc-no` · `data-doc-dept` · `data-doc-date`) · 회사명. 머리말 · 꼬리말 · 쪽번호 없음 | `--br-deep` · `--br-cobalt` |
| 꼬리말 · 쪽번호 | 위 가는 딥 블루 선 · 왼쪽 「회사명 · 문서명」 · 오른쪽 「쪽 / 전체」(명조) | `--br-deep` |
| 수치 타일 | 카드 격자가 아니라 표 짜임 — 옅은 회청 머리 칸 · 값 칸 · 표 선(면 · 둥근 모서리 없음) | 양식 표 색 |
| 여백 | 왼 20mm · 오른 10mm(제본 여백) | — |

## 5. 시각 스타일 — 발표 보고

`deck.yaml` 의 `style:` 한 줄로 고른다. 본문 HTML · 부품 · 검사는 같고 보이는 규칙만 바뀐다(`assets/blue-style.css`).

| | C 혼합형 (`style: c` · 권장 · 스킬 기본) | A 프레임형 (`style: a`) |
|---|---|---|
| 머리띠 · 꼬리띠 | 밝은 띠 + 아래 굵은 남색 선 · 얇은 꼬리띠 | 짙은 남색 띠 둘이 장을 감싼다 |
| 인상 | 정돈된 구조 + 지면감 · 한 장 한 메시지 | 업무 도구 · 대시보드 |

자세한 차이는 `DESIGN.md` 「2-1」.

## 6. 톤
